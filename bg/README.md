# Нито една загубена поръчка

**Por Dorian Chávez, fundador de Hábil y arquitecto de integración.**

**За кого е:** за всеки, който вече работи с терминал и git, чете JSON и знае основите на SQL, и иска да научи
интеграция на системи. Не е нужно да знаеш Java или Camel: маршрутите са на YAML и се учат тук.

**Какво ще знаеш накрая:** как със собствените си ръце да постигнеш това нито една поръчка да не се губи, всичко да
може да се проследи, един повторен опит да не дублира и една паднала дестинация да не събаря останалите.

**Какво ти трябва, преди да започнеш:** терминал и git, четене на JSON и основи на SQL, и Docker с Compose. От Docker
стигат `docker compose up` и `down`; останалото е написано. Работи на Linux, macOS и Windows с WSL.

## Проектът

Един измислен магазин продава и всяка поръчка трябва да стигне до три системи, които не си приличат: един REST API,
един ERP върху MariaDB и един търговски партньор, който получава EDI X12 документи по SFTP. Всичко работи на твоята
машина с Docker. Това е отворен и безплатен практически курс по интеграция на системи с
[Apache Camel](https://camel.apache.org/).
